カメラ映像をリアルタイムでピクセルアートの世界に変換！

F8 Effect は、カメラ映像にリアルタイムでレトロゲーム風エフェクトを適用するカメラアプリです。8ビット・16ビット時代の雰囲気をそのままカメラで体験できます。撮影だけでなく、アルバムの画像を読み込んで編集する機能も搭載しています。

難しい設定は不要。プリセットを選ぶだけで、豊富なカラーパレットとディザリングがいい感じにピクセルアートの質感を作ってくれます。

主な機能

  • 約100種類のカラーパレット — 細かい設定不要なプリセット機能。各項目は個別に調整も可能
  • 14種類のレトロ解像度プリセット — PICO-8、ゲームボーイ、NES など
  • ディザリング — 様々なパターンでピクセルアートらしい質感を表現
  • ブラウン管風エフェクト（RGB Mask） — 懐かしいブラウン管モニターの質感を再現
  • コントラスト・明度・色反転 — 映像の質感を細かく調整
  • ヴィネット・色収差・曲率 — 画面の歪みや色のズレでさらに本物らしさをプラス
  • エッジ検出 — 輪郭を強調したユニークな表現
  • タイマー撮影 — 3・5・10秒に対応
  • アルバム読み込み — 既存の写真にもエフェクトを適用可能

こんな用途に

  • 写真を手軽にピクセルアート風に変換
  • レトロゲーム風コンテンツの制作
  • SNS投稿・アイコン作成
  • ノスタルジックな写真・動画

レトロゲーム好きはもちろん、ピクセルアート（ドット絵）が気になる人にもおすすめです。

作品をSNSでシェアする時は #F8Effect をつけてください！
